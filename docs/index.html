Windows security testing,
without the clutter.

WinRaider is a Python-based assessment toolkit for auditing commonly exposed Windows services, testing authorized credentials, and integrating supported workflows with Metasploit.

Get started → CLI reference
01 · Capabilities

Everything in one focused CLI.

A compact workflow for discovery, authenticated assessment, vulnerability checks, credential auditing, and optional Metasploit integration.

⌁

7 critical services

Scans SMB, RDP, WinRM, NetBIOS, MSRPC, and SSH endpoints across ports 445, 3389, 5985, 5986, 139, 135, and 22.

◈

Authenticated testing

Supports authorized SMB file access, RDP GUI, WinRM shell, and SSH shell workflows using supplied credentials.

⌕

Vulnerability checks

Assesses known issues including EternalBlue, BlueKeep, SMBGhost, WinRM weaknesses, NetBIOS disclosure, and SSH vulnerabilities.

⚿

Credential auditing

Accepts username and password wordlists for controlled credential-security assessments.

✦

Metasploit integration

Can use a locally available msfconsole for supported security-testing workflows.

▣

Clean CLI

Banner, quiet mode, verbose mode, authentication flags, wordlists, and configurable Metasploit options.

02 · Installation

Up and running in minutes.

Use a dedicated Python environment when developing or testing WinRaider.

git clone https://github.com/YOUR_USERNAME/WinRaider.git
cd WinRaider

python -m venv .venv
.venv\Scripts\Activate.ps1

pip install -r requirements.txt
python winraider.py --help
Replace YOUR_USERNAME with the repository owner. Metasploit is optional and only needed for its supported integration workflows.
03 · CLI

Command-line reference.

Start with a target, then add only the options needed for your authorized assessment.

python winraider.py -t 192.0.2.10
python winraider.py -t 192.0.2.10 -v
python winraider.py -t 192.0.2.10 -q
python winraider.py -t 192.0.2.10 -u administrator -p "<PASSWORD>"
python winraider.py -t 192.0.2.10 --users users.txt -w passwords.txt
python winraider.py -t 192.0.2.10 --msfpath "C:\path\to\msfconsole.exe"
-t, --target

Required target IP address.

-u, --username

Username for authenticated testing.

-p, --password

Password for authenticated testing.

-w, --wordlist

Password wordlist.

--users

Username wordlist.

--msfpath

Path to Metasploit msfconsole.

--lhost

Local host IP for supported Metasploit workflows.

-v, --verbose

Verbose output.

-q, --quiet

Quiet mode.
